## How to read this file

- **Short-tail** = 1–3 words, high volume, hard to rank fast (example: water softener)  
- **Long-tail** = 4+ words, lower volume, higher buying intent, easier to win (example: water softener for 1000 litre tank)  
- **Est. India volume** = monthly search band, not an exact Keyword Planner export. Exact numbers should be locked in Google Ads Keyword Planner (India) + Search Console.  
- Google has **no primary-keyword field**. The keyword must sit in the **title**, **description**, and **H1**.

Volume bands used:


| Band      | Est. India searches / month | How we use it                                     |
| --------- | --------------------------- | ------------------------------------------------- |
| Very High | 5,000+                      | Category demand. Hard to rank in Month 1.         |
| High      | 1,500–5,000                 | Main commercial targets                           |
| Medium    | 400–1,500                   | Best Month-1 ranking chances                      |
| Low–Med   | 80–400                      | High intent, easier to rank. Scale-O’s real edge. |
| Low       | under 80                    | Product / tank-size / support queries             |


**Strategy:** do not only chase *water softener*. Win high-intent Medium and Low–Med terms first (*salt-free water softener*, *water softener for overhead tank*, tank-size queries), then build toward *water softener for home*.

# PART 2 — 6 product pages: old vs new

**What we are changing:** Shopify **Search engine listing** (meta title + meta description) and the visible **product title / H1**.  
**What we are not changing:** product URLs / handles (already keyword-rich).

**What was wrong on all 6 (old state)**


| Problem                                     | Why it hurts                                                           |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| Brand-first title (`Scale-O Mini…`)         | People search *water softener for 500L tank*, not the model name first |
| Titles 62–66 characters                     | Mobile Google cuts the end; the keyword can get hidden                 |
| “saltless” instead of “salt-free”           | Lower volume; does not match homepage language                         |
| Hard price / INR in Mini description        | Goes stale when plans change; wastes snippet space                     |
| “Best salt-free…” on combos                 | Unproven claim; weak trust                                             |
| Vague combo copy (“larger homes”)           | No tank count, so Google cannot match dual-tank searches               |
| Combo descriptions too long (170–172 chars) | Google cuts the last benefit                                           |
| HTML `&` risk (Centi)                       | Looks broken in some snippets                                          |


**What the new versions do**

- Keyword at the **front** of the title  
- Title about **44–51 characters** (safe on mobile)  
- Description about **122–149 characters** (shows in full)  
- Language: salt-free + overhead tank + who it is for  
- No coupon, no fake “best”, no unverified “2L+ families”  
- Brand / model kept at the **end** of the title for CTR

Character targets:


| Field            | Target                                                                   |
| ---------------- | ------------------------------------------------------------------------ |
| Meta title       | 50–60 characters (we kept most under 51)                                 |
| Meta description | 145–160 characters (combos can be a bit shorter if the line is complete) |
| H1               | Product name + salt-free + tank size. One H1 per page.                   |
