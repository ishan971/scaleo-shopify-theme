# Scale-O: 6 Product Page Metas (Before vs After)

**Store:** scale-o.com  
**Date:** 24 August 2026  
**Ticket:** SEO: All 6 product pages meta + Shopify SEO  
**Where to paste:** Shopify Admin → Products → open product → **Search engine listing** → Edit → Save  
**Do not change:** product URL handles (already keyword-rich; short URLs already 301 to these)

Google does not use a “primary keyword” field. The keyword must sit in the **page title**, **meta description**, and later the **H1 / first paragraph**.

---

## What was wrong across all 6 (old state)

| Problem | Why it hurts ranking / CTR |
|---|---|
| Brand-first title (`Scale-O Mini…`) | People search *water softener for 500L tank*, not the model name first |
| Titles 62–66 characters | Mobile SERP truncates; keyword can get cut |
| “saltless” instead of “salt-free” | Lower search volume; mismatches homepage language |
| Price / INR in Mini description | Goes stale when plans change; wastes snippet space |
| “Best salt-free…” on combos | Unproven superlative; weak trust |
| Vague combo copy (“larger homes”) | No tank-count or family intent |
| Descriptions too long (combo / Centi) | Google cuts the last benefit |
| HTML `&amp;` in Centi live desc | Looks broken in some snippets |

**What we improve:** keyword at the **front** of the title, 50–60 character titles where possible, 145–160 character descriptions, salt-free + overhead tank + who it is for, no coupon, no fake “best”, no unverified “2L+ families”.

## 1. Scale-O Mini

**URL (keep):** `https://scale-o.com/products/mini-water-softener-500l-750l-tanks`  
**Admin product:** Scale-O Mini Salt-Free Water Softener for 500L-750L Storage Tanks  
**Primary keyword:** water softener for 500 litre tank  
**Secondary:** salt-free water softener for small family; overhead tank 500L-750L; 1-3 members

### Before (live 24 Aug 2026)

| Field | Old value | Chars |
|---|---|---|
| Page title | `Scale-O Mini Salt-Free Water Softener for 500L-750L Storage Tanks` | 65 |
| Description | `Scale-O Mini is a saltless water softener for 500L overhead tanks, ideal for homes up to 3 members. Easy install, no maintenance. Buy at INR 3,500/- only!` | 154 |

**Old problems**

- Title starts with brand + model; query *water softener for 500L tank* is buried
- 65 characters: likely truncated on mobile
- “saltless” is weaker than “salt-free”
- Hard price in the snippet dates badly
- “Storage Tanks” is theme language, not how India searches

### After (paste this)

| Field | New value | Chars |
|---|---|---|
| Page title | `Water Softener for 500L Tank \| Scale-O Mini` | 44 |
| Description | `Salt-free water softener for 500L-750L overhead tanks. Scale-O Mini suits 1-3 member homes. No salt, no plumber, no electricity. Trial from Rs 3,500.` | 149 |

**What we improved**

- Primary keyword at the **start** of the title
- Model name kept at the end for brand CTR
- Description uses salt-free, tank range, family size, and the 3 USPs
- Price kept light as “trial from” so it still matches the ₹3,500 listing without stuffing “Buy at INR”

**H1 / product title (same Admin page, optional same session)**  
Keep capacity in the visible title. Suggested:  
`Scale-O Mini Salt-Free Water Softener for 500L-750L Tanks`

## How to apply (Admin only)

1. Products → open each of the 6  
2. Scroll to **Search engine listing** → **Edit**  
3. Paste **Page title** and **Description** from the After tables  
4. Leave **URL handle** unchanged  
5. Save  
6. Open the live URL → View Source → confirm `<title>` and `meta name="description"`  
7. Google Search Console → URL Inspection → Request indexing  

Theme code already prints these fields. No developer change is required for metas.

**Not in this file:** Nano / Ultra / Mega / Giga, Blog 2, collection H1. Those are other tickets.
