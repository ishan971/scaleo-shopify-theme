## Why the current names are wrong

| Problem | Why it hurts |
|---|---|
| **Too long (57–64 characters)** | Wraps to 2–3 lines on mobile PDP, sticky Add to Cart, cart drawer, and checkout |
| **Looks like an SEO title, not a product name** | Shoppers already on the page do not need a full search sentence as the H1 |
| **“Salt-Free” on all 6** | Every Scale-O unit is salt-free. Repeating it does not help anyone pick Mini vs Semi vs Centi |
| **Model is buried** | The useful bit (Mini / Semi / Centi + tank size) sits in the middle of a long phrase |
| **Hard to scan in cart** | Six almost-identical sentences. Easy to add the wrong size |
| **SEO already lives in the meta title** | Google snippet is already `Water Softener for 500L Tank \| Scale-O Mini`. Stuffing the same sentence into the product name is duplicate, not extra ranking |
| **Combos still read as a paragraph** | “Salt-Free Water Softener for Two 500L Tanks” is 8 words for “2 tanks” |

**Rule:** product name = what the shopper calls it. Meta title = what Google shows. They should not be the same string.

## Why the new names are better

| New choice | Why it is better |
|---|---|
| **39–45 characters** | Fits one line on phone, cart, checkout, and order email |
| **Model first** | Mini / Semi / Centi is how customers and support talk |
| **Size in brackets** | Fast compare: (500L-750L) vs (1000L-1500L) vs (2x 500L) |
| **Still says “Water Softener”** | H1 keeps the category word Google needs. Salt-free stays in the meta description and USP chips |
| **Combos say `2x`** | Clear dual-tank pack. No Mini+Mini SKU jargon, no long “for Two … Tanks” clause |
| **Same pattern on all 6** | Collection, PDP, cart, and sticky bar all look like one family |

Salt-free is still on the page. It just does not belong in the product title of every SKU.
